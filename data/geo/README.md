# Date Geografice România – Granițe Județe (Administrative Boundaries)

- **Fișier:** `romania-counties.geojson`
- **Sursă date:** Date deschise ANCPI / OpenStreetMap / Click That Hood (Code for Germany)
- **Data descărcării:** 8 Noiembrie 2026
- **Descriere:** Conține toate cele 41 de județe ale României + Municipiul București (42 entități administrative).
- **Sistem de coordonate (CRS):** WGS84 (EPSG:4326)
- **Utilizare:** Bază geografică reală pentru proiectarea teritoriilor SVG din jocul CONQUIZ (grupate în 10, 15, 25 și 29 de regiuni de joc conectate topologic).
